# ほしみのダイスロール 1.1.1

Windows用の独立したD100アプリです。ネット接続やPythonの別途インストールは不要です。

[完成品EXE](完成品/ほしみのダイスロール.exe)をダウンロードして起動します。
GitHubのファイル表示画面では、ファイルをダウンロードしてから起動してください。
未署名の個人制作アプリです。別PCでの起動確認は未実施です。

入力例: `CC<=60 【試し振り：宝箱を見つける】`

人物名の登録、ボーナス・ペナルティ、結果コピー、最大500件の履歴保存に対応します。
詳しい操作は[README.txt](README.txt)を参照してください。

## 個人データの移行

人物名と履歴は `%LOCALAPPDATA%\HoshimiDiceRoll\state.json` に保存されます。
EXEには含まれません。移行する場合は両PCでアプリを終了し、このファイルを
移行先PCの同じ場所へコピーします。既存ファイルは上書き前にバックアップしてください。
個人履歴はこのリポジトリへ登録しません。

## ソースとビルド

Python 3.12とTkinterで作成しています。

```powershell
python -m unittest test_dice_logic.py -v
python -m pip install -r requirements-build.txt
.\build.ps1 -Python python
```

実行時に非公開正本を読み込む機能はありません。判定処理はアプリ内の実装です。
正本が変わっても自動更新されないため、更新時は別途照合してください。
