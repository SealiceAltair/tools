ほしみのダイスロール 1.1.1
==============================

小さなWindows用D100ダイスアプリです。
Webブラウザやインターネット接続は使いません。

使い方
------
1. 「ほしみのダイスロール.exe」をダブルクリックします。
2. 「名前…」から、ダイスを振る人物を登録・選択します。
3. Codexが出した最後の一行を入力欄へ貼り付けます。

   CC<=35 【マイン：胸骨の隙間の青い石を小太刀で狙う】

4. 必要なら「通常／ボーナス／ペナルティ」を選び、「振る」を押します。
5. 「結果をコピー」で、表示結果をクリップボードへコピーできます。
6. 「履歴を開く」で保存済みの結果を確認できます。

コマンド内でボーナス・ペナルティを指定することもできます。

   CC+1<=45 【判定名】
   CC(-1)<=45 【判定名】

コマンド内の指定が、画面で選んだ値より優先されます。

データの保存先
--------------
登録名と最大500件の履歴は、次の場所へ自動保存します。

%LOCALAPPDATA%\HoshimiDiceRoll\state.json

「履歴を消す」ボタンで履歴だけを削除できます。

判定と乱数
----------
- 表示形式とボーナス・ペナルティダイスは、ココフォリアで使われるBCDiceの
  「新クトゥルフ神話TRPG」CCコマンドへ寄せています。
- 成功段階は「星みちTRPG」の正本ルールへ合わせています。
- 乱数にはPythonのsecrets（Windowsの安全な乱数機能）を使用しています。
- 成功値0以下は正本ルールに従い、ダイスを振らず「自動失敗」と表示します。
